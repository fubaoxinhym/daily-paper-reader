## 摘要
视觉-语言模型通常将预训练视觉编码器产生的所有令牌投影到大型语言模型中。然而，最终层特征可能丢弃文本、局部属性和空间关系，而高分辨率输入会显著增加上下文长度和推理延迟。我们引入了\method，一种多尺度自适应视觉编码器。\method使用位置相关门控融合来自视觉Transformer的浅层、中层和深层特征，在保留全局语义的同时增强边缘、文本和局部结构。随后，它根据问题相关性、局部信息含量、全局语义和空间覆盖进行基于问题的令牌路由，令牌预算随图像复杂度自适应变化。为减轻压缩损失，我们进一步引入了全量到压缩表示蒸馏和空间多样性正则化。在一个统一的70亿参数语言模型框架的示例性模拟中，\method将SigLIP-SO400M视觉令牌的平均数量从729减少到146（约减少80.0%），在VQAv2、GQA、TextVQA、ScienceQA-IMG和MMBench上的平均得分提高了2.2个百分点，同时将单图像首令牌时间从228毫秒降至129毫秒。我们提供了完整的模型设计和评估协议。所有报告的数字目前仅作为论文组织和实验设计的占位符；正式结论需要实际训练运行、独立复现和官方基准评估。

## Abstract
Vision-language models commonly project all tokens produced by a pretrained vision encoder into a large language model. However, final-layer features can discard text, local attributes, and spatial relationships, while high-resolution inputs substantially increase context length and inference latency. We introduce \method, a Multi-scale Adaptive Vision Encoder. \method uses position-dependent gates to fuse shallow, intermediate, and deep features from a vision Transformer, preserving global semantics while enhancing edges, text, and local structure. It then performs question-conditioned token routing according to question relevance, local information content, global semantics, and spatial coverage, with a token budget that adapts to image complexity. To mitigate compression loss, we further introduce full-to-compressed representation distillation and a spatial diversity regularizer. In an illustrative simulation under a unified 7B language-model framework, \method reduces the average number of SigLIP-SO400M visual tokens from 729 to 146 (approximately 80.0\%) and improves the mean score on VQAv2, GQA, TextVQA, ScienceQA-IMG, and MMBench by 2.2 percentage points, while reducing single-image time to first token from 228\,ms to 129\,ms. We provide the full model design and evaluation protocol. All reported numbers currently serve only as placeholders for paper organization and experimental design; formal claims require real training runs, independent replications, and official benchmark evaluation.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：主流视觉-语言模型（VLM）通常只取视觉 Transformer 的**最后一层特征**，并将所有视觉 token 投影进大语言模型（LLM）。但最终层特征偏向全局语义，容易丢失文本、局部属性、边缘、空间关系等细粒度信息，损害 OCR、计数、属性识别等能力。
- **效率问题**：提升输入分辨率虽能增强细粒度感知，但 token 序列长度随之近似平方增长（如从 224×224 提升到 448×448 约增加 4 倍 token），显著增加视觉自注意力和 LLM prefill 的计算开销与首 token 延迟。
- **已有压缩方法的不足**：平均池化混淆相邻物体；固定查询重采样与具体问题无关；独立 Top-K 剪枝可能集中于少数据区域；TokenPacker 虽表明视觉 token 有冗余，但仍需兼顾全局语义与局部证据。
- **论文定位**：提出 MAViE，一个多尺度自适应视觉编码器，在**保持细粒度感知**的同时**显著压缩视觉 token 序列**，兼顾多模态推理质量与推理效率。

### 2. 方法论：核心技术思想、关键细节与流程

整体流程为：图像 → SigLIP ViT → HMF 门控融合与局部增强 → QATR 问题条件 token 路由 → Projector → 7B LLM，输出答案（见图 1 与公式 1–4）。

#### 2.1 Hierarchical Multi-level Fusion（HMF，分层多级融合）
- **多级特征提取**：从 SigLIP-SO400M/14 的第 8、16、24 层分别取浅层细节、中层结构、深层语义（F_s, F_m, F_d）。
- **统一投影与局部增强**：将三层特征通过可学习权重映射到公共维度；对浅层和中层特征做 3×3 深度可分离卷积（DWConv），引入局部归纳偏置，并用残差连接保持稳定性。
- **位置相关门控融合**：每个空间位置独立学习三组混合权重（softmax 归一化），将浅、中、深层特征加权求和；采用残差结构 `f_i = f_d + γ·f_hat_i`，γ 初始化为 0.1，防止浅层噪声在训练早期破坏深层语义。
- **高频区域增强**：计算每个 token 的局部变化幅度 u_i（与邻域特征的 L2 距离均值），对文字、边界、复杂纹理等高频区域施加**窗口注意力**，增强局部细节而不引入额外全局注意力矩阵。

#### 2.2 Question-conditioned Adaptive Token Routing（QATR，问题条件自适应 token 路由）
- **问题表示**：对 LLM 中 question token 的 embedding 做注意力池化，得到问题向量 q。
- **四维重要性评分**（公式 14–17）：
  - **问题相关性** s_rel：视觉 token 与 q 的余弦相似度；
  - **局部信息量** s_unc：局部变化幅度归一化；
  - **全局语义** s_global：与全图平均特征 f 的余弦相似度；
  - **空间覆盖** s_cover：与已选 token 的最小归一化距离，在序列选择中动态更新，防止 token 聚集在少数显著区域。
  - 默认权重 (λ_r, λ_u, λ_g, λ_c) = (0.45, 0.20, 0.15, 0.20)。
- **动态 token 预算**：复杂度估计器结合局部变化统计、视觉注意力熵和问题向量范数，输出复杂度 c，再将预算 K 设定为 72 至 288 之间、向下取整到 8 的倍数。训练时用 Gumbel-Top-K 松弛，推理时用硬 Top-K。
- **回收未选 token**：将未选中的 token 通过可学习 context query 聚合成 8 个上下文 token，保留背景与整体布局信息（公式 20）。

#### 2.3 训练目标
整体损失 L = L_LLM + α·L_align + β·L_distill + η·L_div，默认 (α, β, η) = (0.10, 0.50, 0.05)。
- **L_LLM**：标准自回归交叉熵。
- **L_align**：sigmoid 全局图文对齐损失，匹配对为正、非匹配对为负。
- **L_distill**：全量特征（AttnPool(F)）到压缩特征（AttnPool(F_out)）的表示蒸馏，损失由 1−cosine 与 MSE 组成。
- **L_div**：基于高斯核的空间多样性正则，惩罚已选 token 在空间上的过度聚集。

### 7. 优点

- **方法设计有针对性**：同时处理“最终层特征丢失细节”和“高分辨率 token 冗余”两个 VLM 中的真实瓶颈。
- **多尺度融合合理**：位置相关门控 + 残差设计减轻浅层噪声干扰；窗口注意力增强高频区域，不增加全局注意力开销。
- **路由机制新颖且有解释性**：将问题相关性、局部信息量、全局语义和空间覆盖四个信号显式结合，可缓解独立 Top-K 的局部聚集问题。
- **信息不浪费**：把被剪掉的 token 聚合为上下文 token，保留背景与布局，降低压缩损失。
- **训练目标完备**：在标准 LM loss 之外引入对齐、蒸馏、空间多样性三重约束，重视压缩稳定性。
- **诚实透明的学术态度**：全文反复强调结果仅占位，并在 NeurIPS Checklist 中逐项声明未完成事项，避免误导读者。
