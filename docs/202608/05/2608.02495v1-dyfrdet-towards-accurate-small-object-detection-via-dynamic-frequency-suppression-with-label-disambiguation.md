## 摘要
尽管过去几十年取得了显著进展，但由于视觉线索不足，准确识别小目标仍然具有挑战性。以往的工作通常试图构建小目标的判别性表示。然而，广泛的频域噪声和标签歧义却被大大忽视，这严重阻碍了准确定位。为了解决这些问题，我们提出了一种名为 DyFrDet 的新型小目标检测（SOD）检测器，它能够通过动态抑制频域中的背景干扰来精确定位小目标。具体而言，我们提出了一种动态频率感知的特征金字塔网络（DyFrFPN），以自适应地抑制低频冗余和过多的高频噪声。DyFrFPN 将层次特征转换为频域表示，并引入动态频带预测器（DBP）以保留用于小目标识别的判别性成分。随后，我们提出了一种新颖的标签消歧模块（LDM），它利用概率分布来显式建模和缓解目标标签的固有歧义，从而有效提高低分辨率小目标的定位精度。大量实验表明，DyFrDet 在多个基准上取得了最先进的性能，表明其在各种具有挑战性的场景中的有效性和鲁棒性。我们的代码可在 https://github.com/ManOfStory/DyFrDet 获取。

## Abstract
Despite the remarkable progress over the past decades, accurately identifying small objects remains challenging because of their insufficient visual cues. Previous works typically attempt to construct discriminative representation of the small objects. However, the wide range frequency domain noises and label ambiguities have been greatly overlooked, which significantly hinders the accurate localization. To address these issues, we propose a novel small object detection (SOD) detector termed DyFrDet, which is able to precisely localize the small object by dynamically suppressing the background distractions in frequency domain. Specifically, we propose a Dynamic Frequency-aware Feature Pyramid Network (DyFrFPN) to adaptively suppress low-frequency redundancy and excessive high-frequency noises. The DyFrFPN transforms the hierarchical features into frequency domain representation, and introduces a Dynamic Band Predictor (DBP) to preserve the discriminative components for small object identification. Afterwards, we present a novel Label Disambiguation Module (LDM), which leverages probabilistic distributions to explicitly model and alleviate the inherent ambiguity of target labels, yielding efficient improvement in localization precision of the small objects with low-resolution. Extensive experiments demonstrate that DyFrDet achieves state-of-the-art performance across multiple benchmarks, indicating its effectiveness and robustness in various challenging scenarios. Our code is available at https://github.com/ManOfStory/DyFrDet.

### 1. 核心问题与研究动机

- **问题背景**：小目标检测（SOD）是通用目标检测的重要子任务，在无人机巡检、遥感定位、自动驾驶等场景中具有关键应用价值。然而，由于小目标在图像中占据的空间像素极少，视觉线索严重不足，直接套用通用检测器往往导致显著的性能退化。
- **现有方法的不足**：主流小目标检测方法主要集中于构建语义判别性的特征表示，但在高度复杂的背景场景下仍面临两大被忽视的挑战：
  - **频域噪声干扰**：小目标极易受复杂背景纹理和细粒度噪声干扰。已有方法（如 HS-FPN）仅通过 DCT 抑制低频分量，但高频干扰依然会严重损害定位能力。
  - **标签歧义问题**：小目标的低分辨率导致边界模糊，人工标注本身存在不确定性（如标注框偏离真实物体中心），这种固有歧义会误导模型训练，阻碍精确回归。
- **核心洞察**：作者通过热力图可视化（图1）证明——若能在频域中同时抑制低频冗余与高频噪声，并将标签回归建模为概率分布而非确定性预测，可以显著提升小目标检测的定位能力。

### 2. 方法论：DyFrDet 架构

DyFrDet 是一个两阶段检测器，由两个核心模块组成：**DyFrFPN（动态频域感知特征金字塔网络）** 和 **LDM（标签消歧模块）**，整体流程如下：

#### (1) 动态频域感知特征金字塔网络（DyFrFPN）

- **频域变换**：将 ResNet-50 骨干网络输出的多尺度特征 {c₂, c₃, c₄, c₅} 经标准 FPN 融合后得到 {p₂, p₃, p₄, p₅}，再通过**快速傅里叶变换（FFT）**将各层特征转换到频域：
  - 频谱左上角区域对应低频信号，右下角区域对应高频信号。
- **动态频带预测器（DBP）**——核心组件：
  1. 将复值频域特征分解为**振幅谱 A** 和**相位谱 Φ**，分别用卷积块处理后再经 IFFT 融合回空间域得到 f。
  2. 对频域特征 f 和空间特征 p 分别施加全局最大池化（GMP）和全局平均池化（GAP），拼接后投影为 **Q（来自空间特征）、K/V（来自频域特征）**，通过缩放点积注意力融合两者的互补信息。
  3. 通过前馈网络（FFN）预测每个通道的**低频抑制阈值 α₁ 和高频抑制阈值 α₂**，采用指数参数化确保阈值非负且可灵活缩放：α₁ = αₗ·e^{dα₁}, α₂ = αₕ·e^{dα₂}。
  4. 根据 α₁、α₂ 生成空间掩码 M：将频谱左上角（低于 α₁ 的低频冗余区域）和右下角（高于 α₂ 的高频噪声区域）置零，中间频带保留。
  5. 频率特征通过 **P′ = P − β·(P ⊙ (1 − M))** 完成软抑制（β 控制抑制强度），最后经 IFFT 还原到空间域，得到增强的多尺度特征 {p*₂, p*₃, p*₄, p*₅}。

#### (2) 标签消歧模块（LDM）

- **概率分布建模**：与传统的确定性边界框回归（L1 损失）不同，LDM 将预测偏移量建模为**高斯分布** P_θ(x) = N(μ, σ)，将真实偏移量建模为**狄拉克分布** Q_gt(x) = δ(x − x_gt)。σ 的最大值 σₘ 反映了预测定位质量——σₘ 越大，目标边界越模糊、标签歧义越严重（图3可直观看出）。
- **KL 散度损失**：训练时最小化预测分布与真实分布之间的 KL 散度，等价于优化：
  - L_LDM ∝ (x_gt − μ)ᵀ(x_gt − μ)/(σᵀσ) + log(σᵀσ)
- **置信度加权**：设计权重函数 ω(σₘ)：

  ```
  ω(σₘ) = 1,  if σₘ ≤ ρ
  ω(σₘ) = ε + (1−ε)·[1 − ((σₘ−ρ)/(1−ρ))²],  if ρ < σₘ < 1
  ```

  即对高质量样本（σₘ ≤ ρ）保持完全权重，对歧义严重的样本（σₘ → 1）降低惩罚力度，从而抑制低质量标注对训练的负面影响。
- **总损失**：L = γ·L_IoU + L_CLS + ω(σₘ)·L_LDM（γ 为平衡系数）。

### 6. 主要结论与发现

- **频域动态抑制有效**：在 AI-TOD 上，DyFrDet（R50+SAC+DyFrFPN）相比 HS-FPN 提升 AP 3.6%、AP_vt 3.1%，验证了同时抑制低频冗余和高频噪声优于仅抑制低频。
- **动态优于静态**：动态频带预测比人工设定的静态阈值带来更优性能（AP 26.0% vs 静态最优 25.3%），表明通道自适应的频域调制更能适应复杂多样的场景。
- **标签消歧有效**：将边界框回归建模为概率分布并加权抑制歧义样本，可稳定带来 AP 提升（约 0.8~1.0 个百分点）。
- **联合增益显著**：两个模块联合使用时获得最佳性能，AI-TOD 上 AP 从基线 23.6% 提升到 26.0%（+2.4%），且在 SODA-A 和 SODA-D 上均达到 SOTA。
- **可视化验证**：DyFrDet 生成的激活热图更集中在前景区域，背景响应被有效抑制，减少了假阳性与漏检。

### 7. 优点与亮点

- **问题切入点新颖**：已有 SOD 方法多聚焦于特征增强或标签分配，本文同时从频域噪声抑制和标签歧义建模两个被忽视的角度切入，问题诊断有清晰的动机和可视化证据支撑。
- **方法设计精巧**：
