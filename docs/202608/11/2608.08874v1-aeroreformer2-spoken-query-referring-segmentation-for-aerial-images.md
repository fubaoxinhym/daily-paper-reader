## 摘要
语音提供了一种自然、免提的接口，用于在密集的遥感影像中指定任意目标，然而现有的指代遥感图像分割基准只接受书面表达。为弥合这一差距，我们引入了\dataset，一个源自RISBench的语音查询基准，在保留原始图像、掩码和数据划分的同时，增加了口音与声音多样化的语音。其困难评估集结合了旋翼、风及混合干扰，并设置了三种信噪比水平。我们还提出了\model，一种高效的双边网络，将边界保持的视觉路径与令牌保持的语音编码、核线性跨模态注意力以及分辨率细化头相结合。该设计在不具体生成密集语音-视觉亲和矩阵的情况下，在两种尺度上条件化视觉特征，随后利用高分辨率视觉特征恢复精细边界。在干净测试划分上，使用Swin-Base的\model实现了62.09%的平均交并比（mIoU）和68.22%的整体交并比（oIoU），分别比最强的音频自适应遥感基线高出5.38和2.08个百分点。同时，它在困难集上保持了54.09%的最佳mIoU。据我们所知，这是针对遥感影像的全句语音查询指代分割的首个基准和模型研究。代码将公开提供。

## Abstract
Spoken language offers a natural, hands-free interface for specifying an arbitrary target in dense remote-sensing imagery, yet existing referring remote-sensing image segmentation benchmarks accept only written expressions. To bridge this gap, we introduce \dataset, a spoken-query benchmark derived from RISBench that adds accent- and voice-diverse speech while preserving the original image, mask, and data splits. Its hard evaluation sets combine rotor, wind, and mixed interference with three signal-to-noise levels. We also propose \model, an efficient bilateral network that combines a boundary-preserving visual path with token-preserving speech encoding, kernel linear cross-modal attention, and a resolution refinement head. The design conditions visual features at two scales without materializing a dense speech--visual affinity matrix, then restores fine boundaries using high-resolution visual features. On the clean test split, \model with Swin-Base achieves 62.09\% mean intersection over union (mIoU) and 68.22\% overall intersection over union (oIoU), outperforming the strongest audio-adapted remote-sensing baseline by 5.38 and 2.08 percentage points, respectively. It retains the best hard-set mIoU at 54.09\%. To the best of our knowledge, this is the first benchmark and model study of full-sentence spoken-query referring segmentation for remote-sensing imagery. The code will be made publicly available.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现有的遥感图像指代分割（Referring Remote-Sensing Image Segmentation, RRSIS）基准（如 RISBench、RefSegRS 等）仅接受书面文本表达作为查询输入。然而在实际部署场景中，分析师或操作员更自然地使用**语音**进行免提交互（如“桥下那辆小车”“最右侧码头旁的船只”），同时需将视觉注意力保持在屏幕上。**文本与语音之间存在显著的声学差异**（口音、音高、语速、性别、麦克风响应、环境噪声等），文本基准无法评估系统对这些声学变量的鲁棒性。
- **研究空白**：虽然已有声音引导分割（AVS）和语音引导分割（如 Wnet、STBridge）等工作，但它们面向自然图像或视频场景，且多使用单词查询或多模态线索，**既不涉及航空遥感影像，也不支持全句关系型口语表达**。遥感图像中目标细小、方向任意、尺度跨度大、依赖长程空间关系，对语音查询提出了独特挑战。
- **论文含义**：该工作是**首个面向遥感影像的全句口语查询指代分割（Spoken-Query Referring Segmentation）研究**，填补了“口语交互+遥感像素级感知”的交叉空白，为构建真正可部署的免提遥感分析系统奠定了基础。

### 2. 方法论

**整体架构**：AeroReformer2 是一个高效的**双边网络**（bilateral network），遵循 ABCNet 的双边效率原则，同时融合视觉细节路径与语义上下文路径，并引入语音令牌级融合。

**核心组成模块**：

- **双边视觉编码**：
  - 浅层细节路径（detail path）在 1/8 分辨率保留边界证据；
  - 层次化上下文路径（context path）输出 1/4、1/8、1/16、1/32 多尺度语义特征；
  - 视觉骨干可选择 ResNet-101 或 Swin-Base；1/32 分辨率使用核线性自注意力获取全局上下文，避免 N×N 空间亲和矩阵。

- **语音编码（Token-Preserving Speech Encoding）**：
  - 使用冻结的 wav2vec 2.0 将波形编码为令牌序列 A = [a₁,…,a_T]，保留令牌序列而非池化为单个句子向量，从而支持词级视觉定位（如空间关系词“最左”“介于……之间”）。

- **置信门控令牌记忆（CGTM, Confidence-Gated Token Memory）**：
  - 为每个语音令牌预测标量置信度 g_t（公式：g_t = σ(W₂·SiLU(W₁·LN(a_t)))）；
  - 有效权重 w_t = m_t·g_t（m_t 为填充掩码）；
  - 置信度同时调制跨模态注意力的统计量以及全局音频 FiLM 分支（式 4：V′ = V ⊙ (1+γ(ā)) + β(ā)），γ、β 为零初始化的仿射投影。

- **语音-视觉核线性注意力（SV-KLA）**：
  - 采用 ELU 正特征映射：q_i = φ(W_q v_i)，k_t = φ(W_k a_t)，u_t = W_v a_t；
  - 先累加固定大小的语音记忆 S = Σ w_t k_t u_tᵀ ∈ R^{d×d} 与归一化向量 z = Σ w_t k_t；
  - 再以 y_i = (q_iᵀ S) / (q_iᵀ z + ε) 条件化每个视觉查询；
  - **关键优势**：完全不构造 N×T 密集亲和矩阵，运算量为 O((N+T)d²)，存储量为 O((N+T)d + d²)，与令牌数 T 呈线性而非二次关系。

- **双尺度双边路由（Dual-Scale Bilateral Routing）**：
  - 1/16 分辨率 SV-KLA 负责粗略语义定位；
  - 结果上采样后与 1/8 上下文特征相加，再经第二个 SV-KLA 进行细粒度语义定位；
  - 融合细节路径后经视觉核注意力（VKA）全局细化，最后上采样至 1/4 分辨率。

- **高分辨率细化头（1/4 Resolution Refinement Head）**：
  - 结合 1/4 骨干上下文（C₄）、上采样的 1/8 语义特征（S₄）和独立的浅层细节路径（D₄），经深度可分离卷积融合后输出 512×512 掩码；
  - 在语音条件化定位完成后恢复精细边界，而无需在更大的 1/4 网格上执行跨模态注意力。

- **损失函数**：BCE + Soft Dice（式 15）。

### 3. 实验设计

**数据集与基准**：

- **VoiceAeroRef**：从 RISBench（源自 DOTA-v2 与 DIOR）派生的口语查询基准，共 **52,466 个可用三元组**（剔除 6 个仅含句号的无效训练表达）。图像、掩码与数据划分完全保留。
- **训练集**：26,294 个源样本，每个源样本有 8 种声音（4×2 口音-性别因子设计：美式/英式/澳式/印度 × 男/女），每 epoch 随机采样一个声音（式 2），避免视觉掩码八倍过采样。
- **验证/测试集**：验证 10,013 个源样本、测试 16,159 个源样本，每源一个类别均衡的干净单声。
- **硬测试集（Hard Set）**：将干净测试语料与旋翼噪声、风噪声、旋翼+风混合噪声三种干扰类型 × 低/中/高三个信噪比等级（15/7.5/0 dB，±1.5 dB 抖动）交叉，构成 9 个条件单元，每单元 1,795–1,796 样本，总样本数仍为 16,159（每源恰好出现一次）。

**对比方法（9 个模型）**：

- 3 个传统基线：Audio U-Net（FiLM 条件化）、Audio FCN-ResNet101、Audio DeepLabV3-ResNet101（均使用池化音频 FiLM）。
- 4 个近期 RRSIS 模型（文本→音频适配）：FIANet、SBANet、STDNet、LSCF（均以 Swin-Base 为骨干，文本令牌替换为共享 wav2vec 2.0 令牌）。
- 2 个 AeroReformer2 变体：ResNet-101 骨干与 Swin-Base 骨干。

**评估指标**：mIoU、oIoU、Pr@τ（τ ∈ {0.5, 0.6, 0.7, 0.8, 0.9}）。

**训练协议**：图像缩放至 352×352，音频最长 8 秒，wav2vec 2.0 base 冻结，40 个 epoch，AdamW，批量大小 8，权重衰减 1e-4，余弦退火，混合精度训练，梯度裁剪 1.0；新初始化参数学习率 2e-4，Swin-Base 骨干单独以 2e-5 优化。

### 6. 主要结论与发现

- **准确率领先**：AeroReformer2-Swin-B 在干净测试集上达到 **mIoU 62.09%**、oIoU 68.22%、Pr@0.9 27.49%，相比最强非本文方法 LSCF（mIoU 56.71%）提升 5.38 个百分点、oIoU 提升 2.08 个百分点。
- **硬测试集鲁棒性**：硬测试集 mIoU 54.09%（相对 LSCF 的 48.46% 提升 5.63 个百分点），在所有 9 个干扰条件单元中均排名第一（边际 3.70–6.37 点）。所有方法在 0 dB 高干扰下均显著退化，证明基准并非良性增强测试。
- **消融贡献**：融合后视觉核注意力（post-fusion KLA）是最关键组件（移除后 mIoU 下降 4.50 点）；1/32 视觉 KLA 贡献 1.01 点；置信门控主要在高重叠阈值（Pr@0.9）起作用（+1.29 点）。
- **效率优势**：在 Swin-Base 方法中，AeroReformer2 参数量最少（182.063M）、峰值内存最低（855.6 MB，比 LSCF 低 13.7%）、延迟介于 FIANet 与 SBANet 之间；跨模态注意力核心状态下，SV-KLA 相比 softmax 注意力在 512×512 输入下实现 4,000 倍的亲和状态缩减与 43.24 倍的计算缩减。
- **语言学发现**：位置/方向线索出现在 73.39% 的表达中，大小/范围线索占 43.81%，证实保留令牌序列（而非池化）对关系型指代至关重要。

### 7. 优点与亮点

- **任务首创性**：首次将全句口语查询引入遥感指代分割，系统构建了包含口音-性别多样性、干扰条件网格的受控基准，并配套合理的采样协议（每 epoch 一源一声）避免训练分布偏移。
- **高质量数据集构建**：严格的源数据质量控制（剔除无效表达）、类别平衡的声音分配、硬测试集采用合成干扰（无外部噪声录制）保证可重复性；语言学统计分析（词频、线索类别、指代物家族）为任务提供了深入理解。
- **架构设计具有针对性**：SV-KLA 的关联式（associative）公式将置信度权重直接纳入充分统计量，双尺度路由分离粗定位与细定位，1/4 细化头在不扩大跨模态注意力网格的前提下恢复边界，设计逻辑连贯。
- **公平的基线控制**：4 个 RRSIS 模型被明确标注为“音频适配”而非照搬原论文结果；视觉骨干和语音编码器在关键对比中受控，能有力归因性能差异。
- **效率分析全面**：同时提供端到端实测（含语音编码器与解码器）与解析计算分析，并明确区分两者的适用范围，避免过度声称。

### 8. 不足与局限

- **语音真实性问题**：所有语音均为神经 TTS 合成，尚未收集真实遥感分析师的自然语音；合成语音在韵律、停顿、口音真实度上与真实语音存在偏差，基准的外部效度有待验证。
- **干扰模拟局限**：硬测试集的旋翼/风/混合噪声为局部合成模型，未使用真实场景录音，也未建模麦克风频率响应、混响、无线电干扰等实际部署条件；论文承认未建模源影像的采集平台。
- **训练算力信息缺失**：未披露训练阶段的 GPU 型号、数量、总训练时长，影响实验可复现性和资源需求评估。
- **消融覆盖不全**：1/4 细化头的消融缺失，无法定量评估该组件的独立贡献；置信门控消融差异较小，需更多实验验证其稳定性（尤其是在硬测试集上）。
- **跨域泛化未验证**：所有实验均在 RISBench 派生的单一基准上进行，缺乏跨卫星/航空影像源、跨地域、跨语言（或多语码混合）的验证。
- **应用局限**：音频长度截断为 8 秒，不支持流式语音；解码器假设查询为单句确定性表达，不支持后续澄清交互或不确定性校准；未评估人机交互工作流中指标提升是否能转化为实际操作效率的提升。
