## 摘要
联合使用RGB与红外（IR）图像可提升无人机视角下的目标检测性能，但现有方法大多以静态或固定权重融合多模态特征，从而忽略了空间上变化的模态可靠性。我们提出EGM-Det，一种用于RGB-IR目标检测的熵引导多模态自适应融合框架。EGM-Det采用双流架构以保留模态特定表示，并引入熵偏移门控融合模块实现自适应多尺度融合。该模块从输入强度、局部熵和跨模态差异中提取浅层熵先验，并利用它们引导局部偏移对齐和空间-通道门控融合。因此，它选择性地聚合可靠的RGB与红外线索，而非均匀地组合异构特征。我们进一步引入跨模态蒸馏以正则化学习到的融合门控并减少融合退化。每个学生分支从与主分支匹配的跨模态教师分支中提取互补知识，同时熵自适应监督强调不确定的模态决策。在DroneVehicle、LLVIP和VEDAI上的实验表明，该方法在所有三个基准上均达到最先进性能；尤其在VEDAI上，EGM-Det比先前方法高出10个百分点以上。

## Abstract
Joint use of RGB and infrared (IR) imagery can improve UAV-view object detection, but most existing methods fuse multimodal features with static or fixed weights and therefore overlook spatially varying modality reliability. We propose EGM-Det, an entropy-guided multimodal adaptive fusion framework for RGB-IR object detection. EGM-Det employs a dual-stream architecture to preserve modality-specific representations and introduces an Entropy Offset Gate Fusion module for adaptive multi-scale fusion. The module derives shallow entropy priors from input intensity, local entropy, and cross-modal discrepancy, and uses them to guide local offset alignment and spatial-channel gated fusion. It therefore selectively aggregates reliable RGB and infrared cues instead of uniformly combining heterogeneous features. We further introduce cross-modal distillation to regularize the learned fusion gates and reduce fusion degradation. Each student branch extracts complementary knowledge from the cross-modality teacher branch matched to the main branch, while entropy-adaptive supervision emphasizes uncertain modality decisions. Experiments on DroneVehicle, LLVIP, and VEDAI demonstrate state-of-the-art performance across all three benchmarks; in particular, EGM-Det outperforms prior approaches by more than 10 percentage points on VEDAI.

## 1. 核心问题与整体含义

- **研究背景**：无人机视角下的目标检测面临小目标、密集分布、任意朝向、复杂背景与光照变化等挑战。RGB 图像提供纹理与结构细节，红外图像对光照变化不敏感并能响应热信号，两者天然互补。
- **核心问题**：现有 RGB-RR 融合检测方法大多采用静态或固定空间权重融合多模态特征，忽略了不同场景、不同空间位置上模态可靠性的动态变化。RGB 与红外图像由不同成像机制产生，其可靠性随位置和场景内容而变化；一个区域可能 RGB 更可靠，另一个区域则红外更突出。缺乏显式的模态偏好建模，导致不可靠或冗余的模态响应仍被传播。
- **整体含义**：论文提出需要显式建模并监督"何时、何地信任哪种模态"，将模态选择作为可学习的、受信息熵引导的自适应过程，而不是仅依赖最终检测目标的隐式优化。

## 2. 论文提出的方法论

### 2.1 核心思想与整体架构

- **核心思想**：以信息熵为中心，构建场景自适应的融合策略，利用双教师蒸馏显式监督模态偏好选择。
- **整体架构**：采用双流（dual-stream）网络结构，RGB 与红外分别由独立分支提取多尺度特征（F_rgb_l、F_ir_l），保留模态特定表示；仅在选定的特征层通过 EOGF 模块进行跨模态交互融合。

### 2.2 熵偏移门控融合模块（EOGF）

EOGF 是该方法的融合核心，包含三个关键技术步骤：

**（1）熵先验构建**：从输入强度图、局部熵图、跨模态差异中提取浅层熵先验 P：
- P = Φ_prior(I_rgb, I_ir, H_rgb, H_ir, I_rgb − I_ir)
- 该先验编码局部结构复杂度、模态显著性、跨模态差异，用于引导后续对齐与门控，而非作为预定义的模态选择掩码。

**（2）偏移对齐**：将 RGB/IR 特征投影到共享嵌入空间，预测偏移场 Δ_l 和置信度 C_l，对 RGB 特征进行可微仿射变换（warping），实现特征空间中的局部修正，而非全局图像配准。

**（3）空间-通道门控融合**：
- 预测双向空间门控 G_l = [g_rgb, g_ir]，满足 g_rgb + g_ir = 1；
- 并行预测通道门控 c_rgb、c_ir；
- 融合结果：F_fus_l = g_rgb ⊙ c_rgb ⊙ F̃_rgb_l + g_ir ⊙ c_ir ⊙ F_ir_l。

### 2.3 选择性多模态蒸馏

- **双教师配置**：两个独立训练并冻结的单模态检测器（RGB 教师、IR 教师）作为教师；熵引导双流检测器作为学生。
- **教师偏好目标构建**：将教师分类输出的逐像素最大置信度归一化为软模态偏好分布 Q_l（公式 6），作为空间门控的监督目标。
- **学生不确定性度量**：用学生空间门控的归一化熵 H_l（公式 7）衡量模态选择的不确定性；信心不足的区域获得更大的监督权重 ω_l（公式 9），且使用 stop-gradient 防止学生通过改变熵来操纵损失权重。
- **教师可靠性加权**：用教师响应的最大值 R_l（公式 8）作为可靠性权重，弱响应位置贡献更少。
- **自适应门控蒸馏损失**（公式 10）：L_adapt_gate 结合教师可靠性、学生熵不确定性与 KL 散度，使监督集中于"教师可靠但学生犹豫"的位置。

### 2.4 训练目标

总损失为：L_total = L_det + α·λ(e)·(L_branch + L_cross + L_adapt_gate)

## 8. 不足与局限

- **教师置信度偏差风险**：教师置信度只能近似模态可靠性，如果教师校准不良或遇到分布外场景（光照突变、恶劣天气等），偏好目标可能带有偏差。
- **训练成本较高**：双教师蒸馏增加训练开销，对资源受限场景不友好。
- **不确定性刻画有限**：门控熵仅表示模态选择的不确定性，未涵盖传感器噪声、域偏移或标注歧义等产生的不确定性。

- **数据依赖**：方法依赖高质量配对数据和标注，对跨模态不一致或标注噪声敏感；尽管论文修正了标注，但这本身也说明现有数据集质量问题可能对其他方法的公平性产生影响。
