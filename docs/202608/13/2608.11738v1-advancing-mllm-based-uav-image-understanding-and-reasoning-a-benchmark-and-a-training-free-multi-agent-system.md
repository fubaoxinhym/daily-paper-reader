## 摘要
基于多模态大语言模型（MLLM）的无人机航拍图像理解与推理对于空中智能至关重要，但面临着极端尺度变化、任意相机朝向和高目标密度等独特挑战。尽管兴趣日益增长，现有评估仍然分散在个别数据集和狭窄任务上，导致在无人机理解与推理能力的统一评估方面存在关键空白。为填补这一空白，我们构建了UAVQA-Bench，这是一个包含从13个公开无人机数据集中提取的1500个人工标注问答对的基准，涵盖6个能力维度和16项任务，采用多项选择和视觉定位两种格式。对UAVQA-Bench上广泛的开放源码和闭源MLLM以及基于智能体的系统的系统评估，识别出三个关键失败模式：领域-工具集不匹配、未检查的错误传播和静态推理。受这些发现启发，我们提出了UAV-MAS，一个用于基于MLLM的无人机航拍图像理解与推理的免训练多智能体系统，包含一个领域特定感知引擎（DSPE），将查询路由到任务合适的视觉工具；一个上下文感知的迭代细化模块（CAIR），验证中间推理以抑制错误累积；以及一个难度感知的自适应搜索机制（DAAS），根据问题难度调整搜索深度。配备32B开源MLLM的UAV-MAS在UAVQA-Bench上达到77.0%的整体准确率，超过Gemini 3 Pro 4.0%，而8B变体比其基础模型提高了8.7%。

## Abstract
Multimodal Large Language Model (MLLM)-based UAV aerial image understanding and reasoning is essential for aerial intelligence yet poses distinct challenges arising from extreme scale variation, arbitrary camera orientations, and high object density. Despite growing interest, existing evaluations remain fragmented across individual datasets and narrow tasks, leaving a critical gap in unified assessment of UAV understanding and reasoning capabilities. To fill this gap, we construct UAVQA-Bench, a benchmark of 1,500 human-annotated QA pairs drawn from 13 public UAV datasets, covering 6 capability dimensions and 16 tasks in both multiple-choice and visual grounding formats. Systematic evaluation of a broad range of open-source and closed-source MLLMs as well as agent-based systems on UAVQA-Bench identifies three key failure modes: domain-toolset mismatch, unchecked error propagation, and static reasoning. Motivated by these findings, we propose UAV-MAS, a training-free multi-agent system for MLLM-based UAV aerial image understanding and reasoning, comprising a Domain-Specific Perception Engine (DSPE) that routes queries to task-appropriate visual tools, a Context-Aware Iterative Refinement module (CAIR) that validates intermediate reasoning to curb error accumulation, and a Difficulty-Aware Adaptive Search mechanism (DAAS) that adjusts search depth to question difficulty. UAV-MAS with a 32B open-source MLLM achieves 77.0% overall accuracy on UAVQA-Bench, surpassing Gemini 3 Pro by 4.0\%, while the 8B variant improves 8.7\% over its base model.

## 2. 本文提出的方法论

**核心思想**：构建一个免训练（training-free）多智能体系统，通过"专用感知工具 + 逐步验证纠错 + 难度自适应搜索"三个方面分别解决领域工具不匹配、错误传播和静态推理问题。

**UAV-MAS 由三个模块组成**：

- **DSPE（Domain-Specific Perception Engine，领域专用感知引擎）**：
  - 设计 5 个面向航拍场景的专用工具：上下文感知缩放（保留边缘语义信息的裁剪放大）、细粒度显式描述、基于 Depth Anything 3 的距离估计、语义定位、带去幻觉的开放词汇检测。其中检测工具通过两阶段确认（存在性验证 + 等间距幻觉框滤波）来缓解密集航拍场景下 MLLM 的系统性幻觉。
  - 采用"逐工具激活"机制：为每个工具分配一个独立轻量 Agent TS，只负责判断"当前图像-问题对是否需要该工具"这一二值决策，避免小模型在多工具联合调度中发生上下文溢出或幻觉激活。

- **CAIR（Context-Aware Iterative Refinement，上下文感知迭代精化）**：
  - 基于 ReAct 框架构建全局推理轨迹，在每次工具调用后增加**步骤级验证**。Agent PV 仅基于当前步骤信息生成草稿答案与线索摘要，阻断历史锚定偏差；Agent CI 将草稿与历史状态比较，按公式 (at, Ct) = (â t, Ĉt)（若可信且答案改变）/ (at−1, Ct−1‖Ĉt)（若可信但答案一致）/ (at−1, Ct−1)（若不可信）进行状态更新。答案改变时全量替换状态，避免冲突假设间的证据污染；答案一致时安全追加线索累积证据。推理结束后由 Agent LA 综合生成最终答案，再由 Agent CI 在长链答案与迭代状态间择优。

- **DAAS（Difficulty-Aware Adaptive Search，难度感知自适应搜索）**：
  - **自适应初始化**：Agent SC 对基座模型直接响应打分 Sinit ∈ [0,10]，映射到三级剪枝阈值 τ = 2/4/6——高置信问题用大阈值避免冗余扩展，低置信问题用小阈值保留探索路径。
  - **一致性引导分支控制**：采用"连续低置信"判定，仅当当前节点和候选节点同时低于阈值时（S′ < τ ∧ S < τ）才剪枝，容忍单步瞬时低置信（如缩放返回模糊子图但后续描述步骤可整合结果）。
  - **最优路径选择**：在所有深度达上限或产出合法答案的路径中，选择**全节点平均评分最高**的路径（P∗ = arg max 1/|Pi| Σ S(N)），而非仅看叶节点；Agent SC 被明确提示对冗长无信息中间步骤施加惩罚，缓解路径长度偏差。所有分支被剪枝时回退到基座模型初始响应。

## 6. 主要结论与发现

- 在 UAVQA-Bench 上，直接使用开源/闭源 MLLM 与现有通用多智能体系统均存在明显性能瓶颈；闭源模型总体占优，更大开源模型在总量上表现更好，但小模型在视觉定位等特定任务上可反超大模型。
- UAV-MAS-32B 在 UAVQA-Bench 上达到 77.0% 的 Overall Accuracy，**超越闭源 Gemini 3 Pro 达 4.0%**；UAV-MAS-8B 相对其基座模型提升 8.7%。
- 相对最强通用多智能体基线，UAV-MAS 取得 5.9% 的领先；三个模块各司其职、互补增益（单模块分别贡献 +2.8%、+6.3%、+6.5% 左右）。
- 在效率方面，DAAS 相比多数投票@3 在相近精度下减少 57.7% 延迟、减少约 30% 的模型调用和 40% 以上的工具调用，证明定向探索优于暴力重复采样。
- 跨数据集实验表明 UAV-MAS 的免训练多智能体架构可泛化到 UAV 之外的遥感场景，具备一定通用性。

## 7. 优点

- **基准设计的严谨性**：UAVQA-Bench 全人工标注（7 名 CV 背景标注者多阶段审查）、采用封闭式客观评分协议，可复现性强；6 个能力维度、16 个任务覆盖从基础感知到高层空间推理再到视觉定位的完整跨度，统计学特征（小目标占比、空间分布、分辨率分布）刻画了航拍场景的真实难点。
- **方法的问题驱动性**：三大失败模式在前期系统评测中实证发现，UAV-MAS 的三模块逐一对应，设计动机清晰。
- **免训练设计**：完全不需要微调，可直接部署在任意开源/闭源 MLLM 上，实用门槛低；补充实验显示可迁移到不同骨干（GLM4.6V、Qwen3.5）与其他领域基准。
- **细节工程处理扎实**：如等间距幻觉框滤波、连续低置信才剪枝（容忍瞬时低置信）、答案改变时全量替换状态防止证据污染、路径选择时对冗长步施加惩罚以避免长度偏差——这些设计体现了对领域问题的深入洞察。
- **效率意识**：不仅报告精度，还报告延迟和调用数，提供了精度-成本权衡的分析。

## 8. 不足与局限

- **推理延迟高**：多智能体迭代推理和工具调用导致显著延迟（单查询仍需百秒级）。作者也承认目前更适合地面站离线分析，不适合无人机机载实时推理。
- **性能仍有天花板**：CAIR 降低但无法根除错误传播；部分情况下模型会把正确答案改为错误答案、遗漏关键视觉信息，或无法客观评估推理步骤收益。人类平均准确率 87.87% 仍是 UAV-MAS（77.0%）之上的明显标杆。
- **基准规模有限**：1,500 个问答对、每任务平均不到 100 个样本，可能不足以支撑细粒度、统计稳健的结论；文本多样性依赖有限数量的模板，存在被模型学习表面模式的风险。
- **视觉定位任务的可选性**：多项选择本身降低难度，真实应用中的开放式视觉问答可能要求更高；视觉定位仅一个正确答案框（无 multiple ground truth 的容错机制，可能低估模型性能）。
- **跨域验证不充分**：仅用 CHOICE 的 440 个多项选择子集，未覆盖 UAVQA-Bench 的全部任务类型（如视觉定位），无法验证 DSPE 专用工具在跨域任务中的通用性。
- **客观性风险**：多智能体系统依赖 Agent SC 主观打分（0-10 分）作为搜索剪枝依据，该分数与模型能力强相关，评分偏差可能系统性影响搜索方向和最终结果。
