## 摘要
无人机（UAV）图像中的视觉定位旨在根据自然语言描述，在复杂的鸟瞰场景中定位目标物体。然而，大量小型、密集分布且视觉相似的目标物体造成了高度的视觉冗余，同时重复的局部配置引发了强烈的拓扑模糊性。现有方法主要关注视觉-语言特征对齐或密集上下文交互，但它们难以区分细微的实例间差异，也未能有效利用空间拓扑结构，从而在高度拥挤的场景中导致定位不准确。为了解决这些挑战，我们提出了GrabVG，一个受人类视觉搜索启发的全新视觉定位框架。GrabVG将定位过程明确地分解为两个连续阶段：预注意假设搜索和图注意力特征绑定。具体来说，我们首先通过蒸馏引导的提议归纳和文本感知的假设过滤来生成一组紧凑且可靠的目标假设，从而大幅减少背景干扰和语义不匹配。随后，这些假设被组织成一个稀疏图，其中语言引导的实例内视觉线索和实例间拓扑关系通过图注意力被联合绑定并传播，从而实现高效的空间推理和准确的目标定位。在AerialVG和AerialSense上的大量实验表明，GrabVG实现了良好的精度-速度权衡，达到了67.31%和80.34%的Acc@0.5，分别比相应的基线高出10.55和8.76个百分点。

## Abstract
Visual grounding in Unmanned Aerial Vehicle (UAV) imagery aims to localize a target object in complex bird's-eye-view scenes according to a natural language description. However, the abundance of small, densely distributed, and visually similar objects creates high visual redundancy, while repetitive local configurations give rise to strong topological ambiguity. Existing approaches mainly focus on visual--language feature alignment or dense contextual interaction, yet they struggle to distinguish subtle inter-instance differences and effectively exploit spatial topological structures, leading to inaccurate grounding in highly crowded scenarios. To address these challenges, we propose $\textbf{GrabVG}$, a novel visual grounding framework inspired by human visual search. GrabVG explicitly decomposes grounding into two sequential stages: $\textit{preattentive hypothesis search}$ and $\textit{graph-attentive feature binding}$. Specifically, we first generate a compact set of reliable object hypotheses through distillation-guided proposal induction and text-aware hypothesis filtering, substantially reducing background distractions and semantic mismatches. These hypotheses are then organized into a sparse graph, where language-guided intra-instance visual cues and inter-instance topological relationships are jointly bound and propagated via graph attention, enabling efficient spatial reasoning and accurate target localization. Extensive experiments on AerialVG and AerialSense show that GrabVG achieves a favorable accuracy--speed trade-off, reaching 67.31$\%$ and 80.34$\%$ Acc@0.5 and outperforming the corresponding baselines by 10.55 and 8.76 percentage points, respectively.

## 1. 核心问题与整体含义
- **研究背景**：无人机（UAV）图像中的视觉定位（Visual Grounding）旨在根据自然语言描述，在鸟瞰视角的复杂场景中定位目标物体。
- **核心挑战**：
  - 目标物体通常**小、密集分布、外观高度相似**，造成严重的“视觉冗余”（visual redundancy）。
  - 俯视视角弱化了透视与深度线索，密集物体在二维平面中形成**重复的局部空间结构**，导致“拓扑歧义”（topological ambiguity）。
- **现有方法不足**：
  - 主流方法偏向视觉-语言特征对齐或密集上下文关系建模。
  - 难以区分“候选级”的细微差异；密集交互中远处的弱相关物体可能干扰局部有效信息。
- **整体意义**：该论文提出将视觉定位视为“先搜索、后绑定”的两阶段过程，以更贴近人类视觉搜索机理的方式，解决拥挤航空场景下的歧义问题。

## 2. 方法论
- **核心思想**：借鉴人类视觉搜索理论（Guided Search 与 Feature Integration Theory），将定位过程显式分解为两步：
  1. **预注意假设搜索（Preattentive Hypothesis Search）**：快速筛选出可能包含目标的候选区域；
  2. **图注意力特征绑定（Graph-Attentive Feature Binding）**：针对剩余候选进行细粒度外观与相对关系的证据绑定。
- **关键技术细节**：
  - **蒸馏引导的提议归纳（Distillation-Guided Proposal Induction）**
    - 使用外部教师模型（如 AerialVG 教师、Grounding-DINO）离线生成“表达式对齐”的伪标注框。
    - 仅在训练阶段使用，验证/推理时不用。
    - 通过 DETR 式解码器学习生成多个前景假设，并用二分匹配与 DETR 损失优化，提升候选覆盖质量。
  - **文本感知假设过滤（Text-Aware Hypothesis Filtering）**
    - 用一个轻量级交叉注意力层将语言信息注入提议特征，计算相关性分数。
    - 保留 Top-K 的高分候选，提前滤除背景和语义不匹配的假设。
    - 过滤分数由 BCE 损失和“保留惩罚项”（避免错误剪掉正解）监督。
  - **实例内外观绑定（Intra-Instance Appearance Binding）**
    - 为每个候选框设置 M 个相对锚点，锚点嵌入受语言条件化后，预测相对偏移。
    - 在候选框内部、边界和周边采样多尺度视觉特征，并通过注意力聚合更新节点表示。
  - **实例间拓扑绑定（Inter-Instance Topological Binding）**
    - 用对称的 k-最近邻（k-NN）图连接候选中心，加入自环。
    - 构造几何描述子（中心位移、距离、方向、尺度比），并结合文本句向量调制边特征。
    - 通过边感知的图注意力层传播邻居信息，最后用可学习门控融合外观与拓扑特征。
  - **最终定位**：采用 PropVG 的 Contrastive-based Refer Scoring（CRS）模块，对每个图节点与文本计算匹配分数，选最高者对应框作为最终输出。
- **整体流程公式化表述**：
  ```
  H0 → 文本感知过滤 → Hf → 实例内绑定 → Ha → 实例间拓扑绑定 → Hg → CRS 打分 → b*
  ```
- **训练目标**：由检测损失（DETR）、过滤损失、定位损失（PropVG）和辅助分割损失共同加权优化。

## 3. 实验设计

  - Top-5 Acc@0.5：前 5 个预测中任一满足 IoU>0.5 的比例；
