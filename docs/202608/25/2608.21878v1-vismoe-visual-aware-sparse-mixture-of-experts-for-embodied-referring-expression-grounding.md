## 摘要
具身指代表达定位是一项使智能体能够在真实环境中导航并根据自然语言指令定位远程物体的任务。在该场景中，智能体需要在每一步选择一个视图用于导航，并在目的地从所有候选物体中识别出特定物体。然而，以往的大多数方法未能区分视图和物体，而是使用普通视觉编码器对它们进行处理，导致视图和物体的表示均存在歧义。为解决上述问题，我们提出了ViSMoE，它为具身智能体赋予了具有视觉感知路由策略的稀疏专家混合模型。该框架专门处理不同类型的视觉信息，从而为视图和物体生成具有判别性的视觉表示。在REVERIE和SOON数据集上的实验结果表明，ViSMoE优于先前的最先进方法，彰显了我们所提出方法的优越性。

## Abstract
Embodied Referring Expression Grounding is the task of enabling an agent to navigate in real environments and to localize a remote object based on natural language instructions. In this scenario, the agent needs to select one view for navigation at each step and identify a specific object among all candidate objects at the destination. However, most of the previous approaches fail to distinguish between views and objects, instead processing them using the vanilla vision encoder, which results in ambiguous representations of both views and objects. To address the above issues, we propose ViSMoE, which equips sparse Mixture-of-Experts with a visual-aware routing policy for the embodied agent. This framework processes different types of visual information specifically, resulting in discriminative visual representations for both views and objects. Experimental results on REVERIE and SOON datasets demonstrate that ViSMoE outperforms the previous state-of-the-art methods, showing the superiority of our proposed method.

- **具体场景**：论文聚焦 REVERIE 和 SOON 两个 benchmark。前者指令较短（平均 18 词），导航路径 4–7 步；后者指令较长（平均 47 词），导航路径 2–21 步，且每个视角平均含更多候选物体（45.8 个 vs. REVERIE 的 3.42 个），视觉与语言复杂度明显更高。
- **现有方法的不足**：以往方法（如 DUET）将离散视图（discrete views）与候选物体（candidate objects）的嵌入直接拼接，使用同一套 vanilla 视觉编码器统一处理。然而，**视图与物体在本质上存在显著差异**：
  - 视图提供房间布局和空间关系的全局概览，物体则聚焦具体物品的细节信息；
  - 视图用于逐步导航决策，物体用于终点目标定位——二者分属不同子任务，数据分布不同，存在多输入、多任务的异构挑战。
  - 统一编码导致视图和物体的表示缺乏判别性，产生表示混淆，影响导航与接地性能。
- **核心问题**：如何在一个统一框架中，对不同类型视觉输入（视图 vs. 物体）进行特异性建模，从而同时提升导航与物体定位的精度？

## 2. 论文提出的方法论

### 2.1 核心思想

- 提出 **ViSMoE（Visual-aware Sparse Mixture-of-Experts）**框架，将**稀疏专家混合（SMoE）**引入视觉编码器，并配合**视觉感知路由策略（visual-aware routing policy）**，使不同专家针对特定视觉输入类型进行专门化处理。
- 核心洞察：不同类型的视觉 token（视图 vs. 物体）应被路由到不同的专家子网络，从而获得区分性的特征表示，避免统一编码造成的语义混淆。

### 2.2 基础模型架构

- 模型基于 DUET 的双尺度图 Transformer 架构，包含四个主要组件：
  - **语言编码器（Language Encoder）**：多层 Transformer，对每个词嵌入加上位置嵌入，获得上下文语言表示 ˆW。
  - **视觉编码器（Vision Encoder）**：离散视图 Vt 和物体 Ot 分别融合相对角度特征 at、边界框特征 bt 和导航类型嵌入 nt，得到初始化视觉表示 V′t 与 O′t；再经全景编码器（Pano，两层 Transformer）获得上下文视觉表示 Vct 和 Oct。
  - **双尺度交叉模态编码器（Dual-Scale Cross-Modal Encoder）**：局部尺度上，视觉特征与语言表示做交叉注意力；全局尺度上，拓扑图的节点表示 H 与语言交叉注意力，融合历史与全局信息。
  - 导航使用全局特征和局部视图特征，物体接地使用局部物体特征。

### 2.3 ViSMoE 的关键技术

- **稀疏专家混合层（SMoE）**：
  - 将视觉编码器和局部交叉模态编码器中的密集 FFN 层替换为 SMoE 层；
  - SMoE 层包含一个路由网络（gated network）和 N 个专家（均为 FFN）；
  - 路由公式为 `G(x) = top-k(softmax(Wg · x))`，最终输出为选中专家输出的加权和：`x̂ = Σᵢ G(x)ᵢ · FFNᵢ(x)`。
- **视觉感知路由策略（Visual-Aware Routing）**（核心创新）：
  - 在路由输入中显式添加**可学习的类型嵌入** bt（视图类型嵌入 bv 或物体类型嵌入 bo），即 `G(x) = top-k(softmax(Wg · (x + bt)))`；
  - 这使得路由网络能感知当前输入 token 的视觉类别，将视图 token 导向某些专家、物体 token 导向另一些专家，形成类别特异性的专家分配；
  - 相比 vanilla SMoE（路由仅依赖 token 内容，无视类别），ViSMoE 显著增强了对异构视觉输入的处理能力。
- **辅助负载均衡损失（Load-Balancing Loss）**：
  - 为避免 token 路由不均衡、部分专家过载或闲置，引入 `L_Aux = α · N Σᵢ pᵢ × fᵢ`（α=0.001），促进各专家上的 token 分配均匀。

### 2.4 训练与推理

- **预训练**：在四个任务上联合优化——掩码语言建模（MLM）、掩码区域分类（MRC）、单步动作预测（SAP）和物体接地（OG），总目标为 `L_P = L_MLM + L_MRC + L_SAP + L_OG + L_Aux`。
- **微调**：使用 DAgger 算法训练导航策略，总目标为 `L_F = L_SAP + L_DA + L_OG + L_Aux`。
- 模型参数（除全景编码器外）以预训练的 LXMERT 初始化。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **REVERIE**：高层级指令，平均 18 词，路径 4–7 步，每个全景配有预定义物体边界框。评估指标包括 TL、OSR、SR、SPL、RGS、RGSPL。
- **SOON**：详细指令，平均 47 词，路径 2–21 步，场景和物体描述更复杂。评估导航和远程接地性能。

### 3.2 对比方法

- REVERIE 对照：CKR、SIA、HAMT、TD-STP、FDA、DUET。
- SOON 对照：GBE、KERM、GridMM、DUET。

### 3.3 主要实验结果

- **REVERIE**（val unseen / test unseen）：
  - 相比 DUET，SR 提升 3.20%（val）和 1.65%（test）；RGS 提升 1.56%（val）和 1.50%（test）；
  - 在 OSR、SPL 等指标上也全面优于对比模型。
- **SOON**（val unseen / test unseen）：
  - 相比 DUET，SPL 提升 3.55%（val）和 0.11%（test）；RGSPL 提升 0.56%（val）和 1.03%（test）；
  - 在 RGSPL 上提升幅度大于 REVERIE，说明 ViSMoE 对视觉和语言复杂度更高的任务优势更显著。

## 6. 论文的主要结论与发现

- ViSMoE 在 REVERIE 和 SOON 两个数据集上均**全面超越此前最先进方法**，验证了稀疏专家混合框架在具身指代表达定位中的有效性；
- 将视图与物体分而治之（不同专家处理不同类型视觉输入）能显著提升视觉表示的判别性，同时改善导航和物体定位性能；
- **视觉感知路由策略是核心贡献**：向路由网络显式注入视觉类型信息，优于 vanilla SMoE 的类别无关路由；
- 负载均衡损失对保证多专家协同工作、稳定提升性能具有重要作用；
- 对于当前任务规模和数据集，**专家数为 4、top-k=2** 是计算效率与性能的最佳平衡点；继续增加专家数收益甚微，top-k 过大反而增加计算开销。
