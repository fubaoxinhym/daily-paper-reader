## 摘要
指代分割（Referring Expression Segmentation, RES）旨在为语言表达式指定的对象生成像素级掩码。现有基于多模态大语言模型（MLLMs）的方法通常依赖单次坐标预测进行视觉定位，该方式将连续空间位置序列化为离散文本标记，可能导致定位偏差和校准误差。为解决这些问题，我们提出DRAgent，一个由MLLM驱动的判别式推理（DR）框架用于RES。DRAgent不要求MLLM生成定位坐标，而是首先构建一个由检测器生成的候选空间，然后运用MLLM作为视觉语义目标判别器。具体而言，MLLM通过两阶段DR机制在潜在干扰物中执行可靠的目标选择，该机制首先筛选高召回候选框，随后进行实例级验证。选定的目标框随后作为空间提示输入基础分割模型以生成最终像素级掩码。此外，我们构建了自一致性过滤的推理链数据管道用于基于LoRA的微调，提供更可靠的监督以增强MLLM的判别式推理能力。实验表明，DRAgent在RefCOCO、RefCOCO+和RefCOCOg上取得了具有竞争力的性能。

## Abstract
Referring Expression Segmentation (RES) aims to generate a pixel-level mask for the object specified by a language expression. Recent methods based on multimodal large language models (MLLMs) often rely on one-pass coordinate prediction for visual localization, which serializes continuous spatial locations as discrete text tokens and may lead to localization bias and alignment errors. To address these issues, we propose DRAgent, an MLLM-driven discriminative reasoning (DR) framework for RES. Instead of requiring the MLLM to generate localization coordinates, DRAgent first constructs a detector-generated candidate space and then uses the MLLM as a visual-semantic target discriminator. Specifically, the MLLM performs reliable target selection among potential distractors through a two-stage DR mechanism, which first screens high-recall candidates and then performs instance-wise verification. The selected target box is subsequently used as a spatial prompt for a foundation segmentation model to produce the final pixel-level mask. Furthermore, we construct a self-consistency-filtered reasoning-chain data pipeline for LoRA-based fine-tuning, providing more reliable supervision for enhancing the MLLM's discriminative reasoning capability. Experiments demonstrate that DRAgent achieves competitive performance on RefCOCO, RefCOCO+, and RefCOCOg.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 指代表达式分割（Referring Expression Segmentation, RES）的任务是根据自然语言描述，在图像中分割出所指对象的像素级掩码，是连接感知与控制的桥梁，在工业或辅助机器人等自主系统中尤为关键。

  - **坐标生成偏差**：MLLMs 在自回归生成空间提示（如边界框）时，将连续坐标序列化为离散文本标记，破坏了坐标的连续性和空间关系，容易产生粗粒度或偏置的定位结果；这种错误会直接传播给下游分割模型。
  - **推理链数据质量不足**：依赖人工标注或外部 MLLM 生成的推理链数据，前者代价高、难扩展，后者可能逻辑不一致，导致模型学到不稳定甚至错误的推理模式。
- 论文的核心观点是：RES 不应被建模为“生成式坐标预测”问题，而应转化为“判别式目标选择”问题——由 MLLM 在检测器生成的候选空间中，通过筛选和验证选出与语言表达式最匹配的目标，再交给分割模型生成掩码。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- **DRAgent** 将 MLLM 的角色从“定位坐标生成器”转变为“视觉语义判别器”。
- 整个流程拆分为三个阶段：候选目标检测 → 判别式目标选择 → 像素级分割。
- 通过“两阶段判别式推理（Two-Stage Discriminative Reasoning, DR）”机制，让 MLLM 在候选空间中做可靠判别，而非直接输出空间坐标。

### 关键技术细节

#### （1）候选目标检测阶段
- 先用 LLM 从文本查询 Q 中提取目标类别 L = LLM(Q)。
- 使用开放词汇检测器 Grounding DINO 生成高召回候选集 O = {o1, o2, ..., on}，每个候选以边界框表示。

#### （2）两阶段判别式目标选择
- **第一层：候选级初步筛选（Candidate-Level Preliminary Screening）**
  - 在图像上用 Set-of-Mark (SoM) 方式可视化所有候选框并编号。
  - MLLM 根据文本查询选择 Top-K 最匹配的候选。
  - 为补偿密集布局下漏检，补充与已选框 IoU 超过阈值 γ 的候选，构成第二层候选集 O_top。

- **第二层：实例级判别验证（Discriminative Verification via Verification Score）**
  - 对每个候选 oi 用 SoM 框单独渲染，并用指令提示 Prompt_DR(Q) 询问“这个红框是否紧贴文本描述的对象？请回答 yes 或 no”。
  - 不使用简单的 argmax 解码，而是基于正负答案 token 集的 logits 构造验证分数：
    - S_i = exp(z_i,V_pos) / (exp(z_i,V_pos) + exp(z_i,V_neg))
    - 其中 z_i,V_pos 是对“Yes/yes/YES” token logits 的平均，V_neg 类似。
  - 最终选择验证分数最高的候选作为目标框。

#### （3）像素级分割
- 将选中的目标边界框作为空间提示，输入分割基础模型 SAM，生成最终掩码。

#### （4）自一致性过滤的推理链数据管道（用于 LoRA 微调）
- **Stage 1 – 自一致性生成**：将目标区域（真实目标或困难负样本）以 SoM 方式渲染，输入 MLLM，要求输出包含“reason（推理链）、description（视觉描述）、answer（Yes/No）”的 JSON 结构化响应。
- **Stage 2 – 自验证**：用 Stage 1 生成的视觉描述 D1 作为新的查询，再次输入 MLLM 进行闭环验证；只有当第一阶段的答案与真实标签一致，且第二阶段对重建描述确认为“Yes”时，该推理链才被保留作为训练数据。
- 该机制过滤掉“只在语言层面自洽、但缺乏视觉证据支持”的推理链，提供更可靠的监督信号。

#### （5）训练策略
- 使用 LoRA 对 MLLM（Qwen3-VL-8B-Instruct）进行高效微调，同时作用于视觉层和语言层，rank 和 α 均设为 16，学习率 5×10⁻⁶，权重衰减 0.01，最大序列长度 2048。

- 将 MLLM 用作“判别式目标选择器”而非“坐标生成器”，能有效缓解定位偏差和对齐错误，提升指代分割的可靠性和性能。

  - 单阶段预训练 MLLM 直接选择目标的效果较差（baseline 66.84% Avg cIoU）；
