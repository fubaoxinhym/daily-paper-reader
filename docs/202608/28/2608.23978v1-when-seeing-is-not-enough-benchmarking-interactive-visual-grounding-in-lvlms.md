## 摘要
视觉定位通常被评估为从信息丰富的指代表达到视觉目标的一次性映射。这种形式忽略了现实世界指称的一个核心属性：目标信息往往是不完整的、模糊的，并通过互动建立。我们为大型视觉-语言模型（LVLMs）中的交互式视觉定位引入了一个受控评估框架，变化了预先提供多少目标信息以及必须通过对话获取多少信息。在四种人类基础视觉情境和四种交互协议中，当前LVLMs的性能显著低于任务级人类基线。当后续问题细化或修正初始目标描述时，交互可以提供帮助。当没有提供初始描述且必须通过问题获取目标信息时，性能最低，这表明主动的、由问题驱动的定位仍然困难。LVLMs的校准也很差，通常报告的置信度超过其经验准确度。后续研究在多种描述来源（人类与AI）、推理努力、重复交互、描述提供者和视觉情境中证实了这些模式。总的来说，交互式视觉定位仍然是一个重要挑战，需要视觉匹配、信息寻求和综合。

## Abstract
Visual grounding is typically evaluated as a one-shot mapping from an informative referring expression to a visual target. This formulation misses a central property of real-world reference: target information is often incomplete, ambiguous, and established through interaction. We introduce a controlled evaluation framework for interactive visual grounding in large vision-language models (LVLMs), varying how much target information is provided upfront and how much must be acquired through dialogue. Across four human-grounded visual contexts and four interaction protocols, current LVLMs perform significantly below task-level human baselines. Interaction can help when follow-up questions refine or repair an initial target description. Performance is lowest when no initial description is provided and target information must be acquired through questions, indicating that proactive question-driven grounding remains difficult. LVLMs are also poorly calibrated, often reporting confidence that exceeds their empirical accuracy. Follow-up studies confirm these patterns across varied description sources (human versus AI), reasoning efforts, repeated interactions, description providers, and visual contexts. Overall, interactive visual grounding remains an important challenge, requiring visual matching, information seeking and synthesis.

### 1. 核心问题与整体含义（研究动机与背景）

- 传统视觉定位（Visual Grounding）被建模为“一次性的、非交互的”映射任务：给定一张图和一条信息充分的指代表达，模型直接定位目标。这种设定隐含一个不现实假设——**指代表达必须是充分且信息完整的**。
- 真实世界中的参考交流通常是**不完整、模糊、依赖上下文，并通过对话协作逐步建立共同理解**的（Clark & Wilkes-Gibbs, 1986）。例如，说话人可能只提供“一个侧身、方脑袋的图形”，听话人需要追问“它是否单腿站立？后腿是否向后伸展？”才能完成定位。
- 现有基准主要测试**静态视觉匹配**能力，而不测试模型能否：识别信息不足、主动提问、整合多轮信息、修正错误选择。
- 本文提出**交互式视觉定位（Interactive Visual Grounding）** 的概念，并设计受控评测框架，系统区分两类关键能力：**视觉匹配能力** vs. **信息寻求与综合能力**。当前LVLMs在这类任务上远未达到人类水平。

### 2. 方法论：核心思想与技术细节

#### (1) 任务形式化
- 一个“指导者”（Director）看到一个有序目标集合 \( D=(d_1,\dots,d_k) \)；
- 一个“匹配者”（Matcher）看到一个独立随机索引的候选集合 \( M=(m_1,\dots,m_n) \)，其中包含目标项以及可能的干扰项；
- 双方看不到对方视图，且索引随机化以避免平凡匹配；
- 匹配者需要通过对话逐步确认每个目标，输出有序预测序列 \( \hat{D}=(\hat{d}_1,\dots,\hat{d}_k) \)；
- 允许匹配者提问、修正先前选择，并在信息不足时暂不决策。

#### (2) 四种交互协议
| 协议 | 初始描述 | 交互方式 | 核心挑战 |
|------|----------|----------|----------|
| STATIC | 完整人工描述 | 无交互 | 静态视觉匹配（一次性） |
| FULL | 完整人工描述 | 可选澄清问题 | 验证、细化或修复初始描述 |
| PARTIAL | 不完整/欠指定属性 | 允许提问 | 恢复缺失信息 |
| NONE | 无初始描述 | 仅能提出是/否问题 | 完全通过提问构建目标表征 |

- 四种协议构成由易到难的信息获取梯度，可分离“视觉匹配失败”和“信息寻求失败”。

#### (3) 指标
- **Accuracy**：正确匹配目标项的比例。
- **Question Rate**：每个目标项平均提问次数。
- **Calibration**：比较模型报告置信度与实际准确率，绘制校准图，并计算 ECE（Expected Calibration Error）。
- **Self-Repairs**：匹配者是否在后续信息下修正先前选择的次数与结果质量。

### 6. 主要结论与发现

1. **LVLMs在交互式视觉定位上显著落后于人类**：
   - 几乎所有模型的准确率都低于任务级人类基线，Tangrams 图集差距最大（如Qwen3-VL-8B平均差距达−61.4%）。
   - 唯一接近人类水平的是 Gemini-3.1-Pro，但也未超过人类。

2. **交互在特定条件下有帮助**：
   - FULL 协议比 STATIC 平均提升 0.6~3.6 个百分点（7/8模型提升），说明澄清问题可以修正/细化初始描述。
   - PARTIAL 下表现不稳定，部分模型能恢复，部分反而下降。

3. **完全问题驱动的定位（NONE）最困难**：
   - 所有模型在 NONE 下均显著低于 STATIC，即使提问最多（NONE > PARTIAL > FULL > STATIC）。
   - 表明LVLMs不擅长主动构建目标表征、提出有效问题并整合答案。

4. **提问数量不等于有效性**：
   - GPT-5.4-Mini 提问最少，静态表现尚可，但 NONE 下大幅落后；
   - Gemini-3.1-Pro 提问多于 GPT-5.5，但 NONE 下准确率却更低，说明提问质量与信息整合更重要。

5. **置信度校准差**：
   - 所有模型普遍过度自信，尤其在 PARTIAL 与 NONE 条件下；
   - 模型能根据信息量调整提问频率与置信度，但置信度并不能可靠反映实际准确性。

6. **自我修复行为稀少且不可靠**：
   - 自我修复仅占匹配总数不足2%，只出现在 FULL/PARTIAL 协议，NONE 下从未发生；
   - 49次修复中仅53.1%将错误改为正确，36.7%是错误替换错误；GPT-5.4即使修复失败，平均自信度仍提升11.2点。

7. **后续实验验证**：
   - AI生成的描述通常比人类描述更容易理解和定位，但协议间相对模式完全一致；
   - 增加推理努力在交互设置中帮助更大，但收益从 Medium 到 High 很快饱和；
   - 多轮重复交互能提升模型表现，但人类仍然领先且校准不稳定；
   - 替代 Director 下模型排名高度稳定（Spearman ρ = 0.929~0.976）；
   - 面部细粒度实验中 FULL 几乎持平 STATIC（差距−0.9 %），而 PARTIAL 和 NONE 分别下降6.8%、18.0%，验证了核心结论。

### 7. 优点

- **问题切入有实际价值**：对“静态视觉匹配饱和但真实Reference需要交互”这一核心矛盾进行了直接回应。
- **受控的实验设计**：通过四种信息供给协议形成认知难度梯度，可分离视觉匹配与信息寻求失败，且每个协议都复用相同的人类数据与提示模板，最大程度控制变量。
- **多维度评估指标**：除准确率外，加入提问率、校准图、自我修复等行为指标，不只关心“对不对”，也关心“模型是否知道何时需要更多信息”。
- **较高生态效度**：使用真实人类对话中的指代表达，覆盖真实物体、抽象图形、可命名/不可命名物体，还包含来自不同人类数据源的重复参考资料。
- **充足的鲁棒性验证**：对描述来源、推理努力、交互轮数、Director模型、领域（面部细粒度识别）均做了后续实验。
- **诚实、明确的Limitation和不可归因声明**：清楚指出协议无法唯一分离子能力，也不宣称涵盖所有视觉场景。

### 8. 不足与局限

- **场景覆盖有限**：仅包含4种物体级视觉语境 + 一种面部细粒度场景，未覆盖：杂乱场景、空间关系/相对定位、开放世界搜索、动态/视频场景等，结论推广需谨慎。
- **模拟Director的现实性**：Director 是 GPT-5.4 模拟，而非真实人类；虽然用替代模型验证了排名稳定性，但不等同于人类Director的信息提供方式。
- **NONE 协议的交互限制过强**：Director 仅回答“是/否/不清楚”，不支持开放性问题，可能与真实人类开放式澄清方式有差异。
- **无法归因具体失败原因**：正如作者自己指明的，协议只是增加信息寻求负担，无法精确区分是提问选择不好、答案整合差、还是对话记忆崩溃等。
- **置信度校准的简化处理**：ECE与准确率强负相关（ρ=−0.96），作者因此主要用校准图而非ECE，说明校准度量本身在该场景下不够独立。
